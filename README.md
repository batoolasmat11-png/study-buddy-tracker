# Study Coach

## Live App URL
[https://study-buddy-tracker-hy7q.vercel.app](https://study-buddy-tracker-hy7q.vercel.app)

## Problem Statement
Students frequently experience burnout, poor study scheduling, and unhealthy habits during intensive study sessions. Study Coach provides an instant, personalized study schedule, practical dietary tips, and a motivational boost based on a student's daily study hours, stress level, and food intake.

## Key Features
- **Interactive Daily Reflection Form:** Input planned study hours, mood/stress level, and diet quality.
- **AI Plan Generation:** Generates customized time blocks, nutritional guidance, and encouraging words.
- **Responsive UI:** Clean, modern interface accessible across mobile and desktop.

## AI Feature & System Prompt
- **Model / Provider:** Lovable AI Gateway / GPT-5.5
- **System Instructions:** 
  > "You are an empathetic academic coach and nutritionist. Analyze the user's study hours, current mood, and diet input. Generate a structured response containing: 1. A realistic study time breakdown. 2. A practical diet/hydration tip based on what they ate. 3. A motivational message tailored to their mood."

## Tools & Tech Stack
- **Frontend / Framework:** React, Tailwind CSS, Vite (Built via Lovable.dev)
- **Deployment & Hosting:** Vercel
- **Version Control:** GitHub
