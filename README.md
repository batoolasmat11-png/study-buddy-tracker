# Study Buddy AI (Lovable)

This project is a study planner web app built using Lovable.dev.

## Features
- Generates personalized study plans
- Considers study hours, mood, and diet
- Provides motivational and structured guidance

## AI Approach

This project simulates AI behavior using rule-based logic.

Instead of calling external AI APIs, the system uses conditional logic to generate personalized responses based on user input.

## Reason for This Approach

- Avoid exposing API keys in frontend applications
- Follow best practices for security
- Ensure the app runs fully client-side without dependencies

## Note

This is a simulated AI system designed to demonstrate:
- Personalization
- Decision logic
- User experience design

Future improvements could include integrating a real AI model via a secure backend.
